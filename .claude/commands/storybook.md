Ученик написал /storybook (или «сторибук», «раскадровка», «пришли скриншоты», «как ты это видишь»). Это согласование
скриншотами: кадры ролика картинками, видео не рендерить, пока ученик не скажет «ок». Компьютер почти не нагружается.

1. Какой ролик: названный учеником, иначе последний в работе (самая свежая папка в `engine/src/mine/`).
   Ролика ещё нет — смонтируй по навыку `ai-montage` (раздел 4) до шага 10 включительно, без рендера.
2. `npm run frames -- <slug>` (в папке `engine`) → лист `engine/reviews/<slug>-vNNN/sheet.jpg`, кадры каждые 2 секунды
   с номерами К001, К002… (по отдельности — в той же папке). Открой лист ученику: Windows `start "" "<путь к sheet.jpg>"`,
   Mac `open "<путь>"`, и скопируй его в папку результата как `кадры.jpg`.
3. Коротко опиши ролик по кадрам (2–4 строки) и спроси: «Ок — рендерю. Или правки по номерам: «К003: …»».
4. Правки — исправь, новый лист кадров, снова покажи. «Ок» — рендер финала (шаг 11 навыка).
5. Хочет увидеть движение, а не картинки («покажи, как двигается», «доску со сценами») — `npm run draft -- <slug>` (лёгкий
   черновик 720p), `npm run board -- <slug>`, `npm run board:open` в фоне и ссылка http://localhost:4321: доска со сценами-клипами,
   оценками, комментариями и стрелками на кадрах (раздел 5 навыка).
