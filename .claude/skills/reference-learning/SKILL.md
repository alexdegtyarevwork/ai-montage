# Дообучение на референсах

Автоматического «перенеси стиль с этого ролика» для моушн-дизайна нет. Работает связка: **измерить референс, записать паспорт стиля,
собрать по паспорту, сверить с референсом**. Замеры бесплатные и локальные, видеокарта не нужна. Глаза тут твои: числа показывают
ритм и палитру, а хук, типографику и характер движения ты берёшь из кадров.

Учимся стилю, а не копируем ролик. Чужие кадры, звук, лица, логотипы автора и дословные тексты в наш ролик не попадают.

Все команды и пути ниже — в папке `engine` (кроме `Стили/…` и «Референсы»: они в корне набора).

## 0. Нельзя

1. Брать в свой ролик кадры, записи, голос, музыку, логотипы и тексты референса. Берём приёмы: ритм, механику, роль цвета, плотность.
2. Класть копии референсов куда-то, кроме `work/_refs/` (папка не уходит в git), коммитить их, публиковать, загружать в облако или
   отправлять в чужие сервисы без слова владельца.
3. Заполнять раздел паспорта «по общим соображениям». Не видишь по кадрам: пиши «не видно» и почему.
4. Брать пароли и cookies из браузера владельца, чтобы скачать ролик. Не скачался: попроси файл (раздел 2, шаг 1).
5. Запускать замер одновременно с рендером, `npm run frames` или студией. Один тяжёлый процесс за раз, иначе всё идёт в разы дольше.
6. Подключать платные сервисы без слова владельца. Ключ (Gemini и другие) ученик присылает в чат, ты сам вписываешь его строкой
   в `engine/.env` (например `GEMINI_API_KEY=…`) и больше нигде значение не показываешь.
7. Тексты для владельца: короткие предложения, на «ты», без длинных тире и штампов (правило набора, `.claude/skills/ai-montage/SKILL.md`).

## 1. Что нужно на компьютере

- Python 3.10 или новее и ffmpeg ставит установщик набора (проверка — `npm run doctor`). В командах ниже `python3`;
  на Windows вместо него `python` (или `py -3`).
- Пакеты замера ставишь ты сам, ученику ничего делать не нужно. Скрипты сами ничего не ставят: если пакетов нет, печатают команду.
  Ставь всегда в отдельное окружение (venv), не в системный Python:
  ```text
  python3 -m venv work/_refs/.venv
  work/_refs/.venv/bin/python -m pip install -r scripts/ref-requirements.txt          # Mac
  work\_refs\.venv\Scripts\python -m pip install -r scripts/ref-requirements.txt      # Windows
  ```
  Дальше запускай скрипты Python из этого окружения: `work/_refs/.venv/bin/python` (Mac) или `work\_refs\.venv\Scripts\python` (Windows);
  в командах ниже это и есть `python3`. Пакет `opencv-python` закреплён ниже 5-й версии: в OpenCV 5 нет каскадов Haar, по которым ищется лицо.
- Необязательно: `mediapipe` (лицо точнее), `librosa` (темп музыки, флаг `--beats`). См. `reference/05-optional.md`.

## 2. Шаги

### Шаг 1. Принять референс
Ученик кладёт ролик-пример в папку «Референсы» или прикрепляет его в чат. Ты сам копируешь его для замеров в
`work/_refs/<имя>/ref.mp4` (любое расширение видео), имя короткое латиницей (`ghtricks`, `anna-reels`). Ученика в эту папку не посылай.
- Ученик дал ссылку: попробуй `yt-dlp -o "work/_refs/<имя>/ref.%(ext)s" "<ссылка>"` (если `yt-dlp` стоит). Instagram часто не отдаёт видео без входа.
  Не вышло с первого раза: не лезь в браузер владельца, скажи просто: «Эту ссылку я не могу открыть. Скачай ролик на телефон или компьютер
  и положи файл в папку „Референсы“ (или прикрепи сюда)».
- Расшифровка нужна для темпа речи и текста хука (необязательно): `npm run transcribe -- work/_refs/<имя>/ref.mp4 work/_refs/<имя>/words.json --lang ru`
  (язык ролика: `--lang en` для английского). Модель распознавания уже стоит после установки. Это тяжёлый процесс, не запускай его параллельно с замером.

### Шаг 2. Замер
```text
python3 scripts/ref-analyze.py work/_refs/<имя>/ref.mp4
```
Рядом с роликом появятся `profile.json` (все числа), `sheet.jpg` (кадр раз в секунду с подписью времени, оранжевая черта: в эту секунду сменилась сцена),
`hook.jpg` (кадры 0, 0,5 … 3 с крупнее) и папка `shots/` (средний кадр каждого плана). В консоли короткая сводка. Что значит каждое поле:
`reference/01-measurements.md`. Главное число темпа это `rhythm` (смены сцены: склейки плюс хлысты, смаз и переезды камеры). Число «планов» детектор считает только по резким
склейкам, у роликов с камерой по холсту оно занижено. Склеек подозрительно мало или много: перезапусти с `--threshold 2` (чувствительнее) или `--threshold 5` (грубее) и сверь с листом.

### Шаг 3. Смотреть глазами
Открой картинки инструментом чтения изображений, по порядку:
1. `hook.jpg`: что в кадре 0, сколько слов, насколько крупно, что движется до 3-й секунды.
2. `sheet.jpg`: смена фонов, цветовые зоны, где появляется человек, как часто меняется картинка.
3. 6…10 кадров из `shots/`: первый, самый короткий и самый длинный план, последний. Склеек мало: открой кадры в секундах `rhythm.times` и `motion.peaks_s` на листе
   (оранжевые черты) и определи, что там меняется: склейка, хлыст, переезд камеры.
Не пересказывай числа вместо кадров и не угадывай шрифт по памяти: смотри на буквы.

### Шаг 4. Паспорт стиля и стиль ученика
1. Рабочий паспорт: скопируй `templates/STYLE.md` в `work/_refs/<имя>/STYLE.md` и заполни по `reference/02-style-passport.md`: хук, раскладка,
   типографика, палитра (из `profile.json`), словарь движения, плотность, субтитры, звук и музыка, что берём, что НЕ копируем, ближайший стиль каталога и отличия.
2. **Итог для ученика** — `Стили/<название>/ПРАВИЛА СТИЛЯ.md` в корне набора по шаблону `Стили/_ШАБЛОН/ПРАВИЛА СТИЛЯ.md`: вид субтитров,
   начало ролика, режим текста, раскладка, цвета, плашки и графика, переходы и темп, звуки, особые правила. Коротко, словами шаблона.
   Название — как назвал ученик, иначе по ближайшему стилю или по приёму («Белый лист с плашками»). Кадры и файлы референса туда не клади.
3. Покажи ученику стиль короткой сводкой в 8…10 строк (хук, раскладка, цвета, темп, ближайший стиль, что не копируем).
   «Остановки: да» в `ПРАВИЛА/1 Настройки.txt` — жди «ок» или правок. «Остановки: нет» (по умолчанию) — не жди, иди дальше и назови выбор в ответе.

### Шаг 5. Вариант стиля в коде
Не с нуля: возьми ближайший стиль каталога и перенеси отличия паспорта параметрами (палитра, шрифты, длительности, переходы, раскладка спикера).
Порядок и таблица «поле паспорта → что менять в коде»: `reference/03-code-variant.md`. Результат: **тестовая сцена 10…15 секунд** на демо-данных или на
первых блоках настоящего ролика. Кадры: `npm run qa -- <композиция>`, затем `npm run frames -- <композиция>` (по одному, не вместе). Правила качества
навыка `ai-montage` (раздел 4, шаг 10, и `ПРАВИЛА/4 Кадр, лицо и наложения.md`) действуют и здесь: кадр 0 не пустой, огромная фраза-хук — только
если она есть в стиле (паспорт, раздел 1) или её попросил ученик, текст в контейнерах, безопасные зоны Instagram.

### Шаг 6. Сверка
Собери черновик тестовой сцены (`npm run draft -- <композиция>`, файл `out/<композиция>-draft.mp4`) или возьми папку кадров `reviews/<композиция>-vNNN` и сравни:
```text
python3 scripts/ref-compare.py work/_refs/<имя>/profile.json out/<композиция>-draft.mp4 --out work/_refs/<имя>/compare
```
Получишь таблицу «референс | наш | отличие | оценка», подсказки, что крутить, и лист `compare.jpg` «референс | наш» рядом (хук и ролик целиком). Покажи лист владельцу
и скажи по-человечески, что отличается. Крути параметры по `reference/04-compare-tuning.md`, не больше трёх кругов: числа показывают, насколько далеко
от референса, а красиво ли, решают глаза и владелец. Таблицу из `compare.md` вставь в раздел 13 рабочего паспорта.
«Остановки: да» — жди, пока владелец посмотрит `compare.jpg` и скажет, подходит ли. «Остановки: нет» — реши сам по листу и назови в ответе, что совпало, а что нет.
Правки, которые изменили вид, перенеси в `Стили/<название>/ПРАВИЛА СТИЛЯ.md`.

### Шаг 7. Запомнить и использовать
Итог лежит в `Стили/<название>/ПРАВИЛА СТИЛЯ.md`, замеры — в `work/_refs/<имя>/` (`profile.json`, `STYLE.md`, `sheet.jpg`, `compare/`).
В следующих роликах стиль берётся как любой стиль из «Стили» (навык ai-montage, раздел 4, шаг 6): ученик назвал его в чате или в настройках,
или он там один. Текст референса в сценарии не используется, только приём хука одной строкой (раздел 1 паспорта).

## 3. Где что лежит

| Путь | Что | В git |
|---|---|---|
| «Референсы» (корень набора) | ролик-пример, который положил ученик | нет |
| `work/_refs/<имя>/ref.mp4`, `words.json` | копия ролика для замеров | нет, папка `work/` в `.gitignore` |
| `work/_refs/<имя>/profile.json`, `sheet.jpg`, `hook.jpg`, `shots/` | результат замера | нет |
| `work/_refs/<имя>/STYLE.md`, `compare/` | рабочий паспорт, сверка (`compare.jpg`, `compare.md`) | нет |
| `Стили/<название>/ПРАВИЛА СТИЛЯ.md` (корень набора) | итоговый стиль ученика | нет, это файлы ученика |
| `src/styles/<имя>.tsx` или `src/reels/<имя>/` | вариант стиля в коде | да, это наш код без чужих кадров |
| `scripts/ref-analyze.py`, `ref-compare.py`, `ref-requirements.txt` | инструменты | да |
| `templates/STYLE.md`, `Стили/_ШАБЛОН/ПРАВИЛА СТИЛЯ.md` | шаблоны паспорта и стиля | да |

## 4. Время и цена

Замер ролика в 45…60 секунд: около 50 секунд на ролик 47 секунд 1440×2560 при 60 к/с (замер 10.10.2026 на обычном компьютере без видеокарты в работе, один процесс; 4K и более длинные ролики идут дольше). Сверка с нашим mp4 около минуты (замер нашего ролика плюс лист «референс | наш»), по папке кадров около 15 секунд. Деньги не нужны: всё считается на компьютере, ключи не нужны.
Платное только в разделе «По желанию» и только по слову владельца.

## 5. Если не получилось

| Симптом | Лечение |
|---|---|
| «Не хватает пакетов» | команда из раздела 1 (в окружение `work/_refs/.venv`); Python старше 3.10 — запусти установщик набора снова |
| Нет ffmpeg | `npm run doctor`, строка про ffmpeg |
| Планов 1 или 3 на ролике, где явно много сцен | плавные переходы, хлысты и камеру по холсту детектор не видит. Темп смотри по `rhythm` и оранжевым чертам листа; можно `--threshold 2`; впиши в паспорт, что считал по листу |
| Склеек очень много на спокойном ролике | мигание или 3D-вращение даёт ложные склейки: `--threshold 5` |
| Лицо «не найдено» при человеке в кадре | стилизованное лицо, поворот или маленькое окно: Haar такое не ловит; определи раскладку по кадрам сам и впиши в паспорт (необязательный `mediapipe`: `reference/05-optional.md`) |
| Лицо найдено там, где его нет | ложные срабатывания на графике: смотри `face.detect_rate` (меньше 0,3 не верь) и кадры |
| Путь с кириллицей, scenedetect не открывает | скрипт сам пробует копию с простым именем во временной папке; если не вышло, переименуй копию в `work/_refs/` латиницей |
| Ссылка не скачивается | раздел 2, шаг 1: просишь файл |
| Референс на другом языке | `npm run transcribe … --lang en` (или код языка), либо пропусти темп речи |
| Замер долго идёт | идёт один проход по ролику и поиск склеек; не запускай параллельно рендер, на слабом компьютере 4K-референс идёт дольше |
