# От паспорта к коду: вариант стиля

Не пиши с нуля. Возьми ближайший стиль каталога (`patterns/README.md`, таблица 21 стиля) и перенеси отличия паспорта параметрами.
Метод и блоки переносятся, карта монтажа каждый раз новая (`ai-montage`, раздел 0, правило 6).

## 1. Выбор ближайшего стиля

Сначала раскладка спикера (`face.layout`), потом настроение (палитра и светлота фона), потом плотность (`shots.per_minute`).

| Раскладка в референсе | Кандидаты в каталоге |
|---|---|
| лицо внизу крупно, запись на нижней половине (`half`) | ЭКСПЕРТ (13), APPLE DEPTH (11), ПОДКАСТ (12); формат 1 |
| полоса 35% внизу с альбомной записью (`strip_card`, лицо мельче) | ЭСТАФЕТА 35% (20), ЛИНЗА с полосой (14), СИМБИОЗ (19); ближе всего формат 4, полоса — `patterns/techniques/speaker-strip-35.md` |
| карточка спикера снизу по центру | СТЕКЛО (2), ЭКСПЕРТНОЕ СТЕКЛО (9), PRISM (5), ПОРТРЕТ-КВАДРАТ (10); формат 4 |
| кружок или рамка, которая ездит по кадру (`small_window`) | ПОРТРЕТ-КВАДРАТ (10); ближе всего формат 2 (окно в углу) |
| лицо во весь кадр (`full`) | формат 3 (карточка спикера), КАНВАС (1) с окном в углу |
| лица нет (`none`) | PULSE (8), ORBIT (6), ПОСТЕР (3), ЛИНЗА без записи; формат 5 |

| Настроение (палитра) | Кандидаты |
|---|---|
| светлая платина, стекло | PRISM, СТЕКЛО, ЭКСПЕРТ |
| белый холст в клетку, капсулы | ЛИНЗА |
| тёплый лист или бумага, оранжевая плашка | ЛИСТ (15), СИМБИОЗ (19), TRACE (7) |
| тёмный космос, глубина | ORBIT, APPLE DEPTH |
| цвет по сервису, один предмет проходит весь ролик | ЭСТАФЕТА 35% |
| огромная типографика, штрихкоды | ПОСТЕР (3) |

Плотность: больше 40 планов в минуту это сцены с жёсткими стыками (СЦЕНЫ, СИМБИОЗ), 10…20 это камера и холст (ЛИНЗА, КАНВАС).
Запиши выбор и причину в раздел 11 паспорта. Не уверен между двумя: «Остановки: да» — покажи владельцу `public/style-previews/styles.jpg` и спроси; «Остановки: нет» (по умолчанию) —
выбери сам и назови выбор с причиной.

## 2. Поле паспорта и параметр в коде

| Поле паспорта | Где это в коде |
|---|---|
| Палитра | путь А: константы `INK`, `SUB`, `ORANGE`, `MINT` и массивы `TINTS`/`PAPERS` в начале `src/styles/<стиль>.tsx`, `skin` (`ink`, `accent`, `panel`); путь Б: константы цветов образца и `src/kit/*` |
| Фон | путь А: `Background` стиля (фон меняется от `i` блока); путь Б: сцены `BLOCKS` образца |
| Шрифты | `public/fonts`, подключение в `src/fonts.ts`; константа `SANS` и поле `skin.font`; акцентное слово другим шрифтом |
| Переходы | путь А: `transition: (i, f) => whip(...)`; доступны `portal`, `blurThrough`, `bloom`, `whip`, `shrinkTo`, `lift`, `stripCut` из `src/kit/presentations`. Длина стыка `TRANS` в `src/styles/engine.tsx` (0,5 с) |
| Плотность и темп | время начала блоков `at` в данных ролика; число блоков; число элементов в блоке (`items`, `nodes`) |
| Кинетика текста | `Words` в `src/styles/parts.tsx`, готовые эффекты `src/kit/remocn/` (маркер, глитч, подъём по буквам, барабан слов) |
| Раскладка спикера | путь А: `speaker` стиля (`card`, `square`, `roam`, `circle`, `half`, `podcast`) и `zone` (где графика); путь Б: `SpeakerStrip`, `SpeakerCam` |
| Субтитры | путь А: `captions: (f) => ({...f.captions, light: true})`, размер и положение в `CaptionSpec`; путь Б: `Captions` из `src/montage/Captions.tsx` |
| Звук | только из каталога `public/sfx/pack/КАТАЛОГ.md`; путь А: `sfx: {move, pop, tick, count}` — имя звука (`'whoosh'` → `sfx/whoosh.wav`) или путь из каталога (`'sfx/pack/pop/pop-09.wav'`) |

## 3. Путь А: вариант стиля на движке

1. Скопируй ближайший `src/styles/<стиль>.tsx` в `src/styles/<имя>.tsx` (имя латиницей, id в верхнем регистре).
2. В копии поменяй палитру, фон, переходы, звуки, субтитры, раскладку спикера по паспорту. Остальное оставь: движок и блоки данных те же.
3. Зарегистрируй в `src/styles/index.tsx`: импорт и строка в массив `STYLES` (`{id: 'MYSTYLE', def: MYSTYLE, demo: shortDemo}`).
4. Для тестовой сцены на 10…15 секунд задай `demo`: `{...DEMO, duration: 14, blocks: DEMO.blocks.slice(0, 4), words: DEMO.words.filter((w) => w.start < 14)}`
   (`DEMO` из `src/template/demo.ts`). Композиция появится в студии в папке Styles как `MYSTYLE-Reels`. Для проверки на настоящем ролике: `npm run new -- <slug> TRACE`, затем
   в `src/mine/<slug>/project.ts` замени `STYLE = 'TRACE'` на id своего стиля.
5. `npm run qa -- MYSTYLE-Reels`, затем `npm run frames -- MYSTYLE-Reels` (по одному). Смотри кадры К001…, первые 3 секунды отдельно.

## 4. Путь Б: ролик по образцу

Подходит, когда стиль не ложится на блоки `hook`, `list`, `stat`, `logos`, `flow`, `cta` (камера по холсту, полоса 35%). Как в разделе 4Б `ai-montage/reference/04-build.md`:
`npm run new -- <имя>-test custom`, затем код ближайшего образца из `src/reels/` копируется в `src/mine/<имя>-test/Reel.tsx`
с блоком «файлы проекта» из шаблона (запись, голос, слова и частоту он подставляет сам), меняются карта сцен и блоки. Тестовая сцена берёт первые 10…15 секунд.

## 5. Тестовая сцена 10…15 секунд

- Кадр 0 уже полный. Огромная фраза-хук — только если она есть в паспорте (раздел 1) или её попросил ученик.
- В сцене есть хотя бы один стык и один блок с данными (список, число, схема), иначе не видно словаря движения.
- Демо-данные честные: никаких выдуманных цифр и логотипов; логотип сервиса из `public/brand`.
- Файлов референса в `public/` и в коде нет, цвета и приёмы вписаны своими числами.
- Затем сверка: `SKILL.md`, шаг 6.
