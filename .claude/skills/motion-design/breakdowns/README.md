референса в разборах заменено словом «Бренд».

## Картинки `img/`

- `*-overview*.jpg` — весь ролик 2 кадра/с с таймкодом.
- `A-open`, `A-punch`, `A-exit`, `A-write`, `A-pill`, `A-screen`, `A-drum`, `A-lens`, `A-smear` — ключевые места A, каждый кадр.
- `B-logo`, `B-whip`, `B-icons`, `B-simple`, `B-mark`, `B-obj`, `B-slide` — ключевые места B, каждый кадр (только сам ролик, без рамки).
- `C-drop`, `C-period`, `C-expand`, `C-words`, `C-iris`, `C-disc`, `C-grid`, `C-stairs`, `C-card`, `C-impact` — ключевые места C, каждый кадр.
- `C-sound.jpg`, `A-music.jpg`, `B-music.jpg` — спектрограммы (у A и B только музыка с эффектами, голос вычтен htdemucs)
  со словами, энергией движения (оранжевая) и разницей кадров (красная).
- Второй проход (каждый кадр): `A-ghost-words` (призрак слова, дрейф искры), `A-interface` (чип → поле, печать 120 зн/с,
  чипы уходят), `A-lens-caret` (лупа схлопывается в каретку), `B-line-slots` (строка на финальных местах, уголки, штрихи),
  `B-icons-orbit` (иконки по одной, грозди меняются местами), `B-mark-behind` (надпись из-за знака конвейером),
  `B-slot-brake` (карусель тормозит), `C-morph-every-frame` (сжатие и вход с поворотом у каждого знака),
  `C-click-counter` (курсор ждёт, клик, счёт каждый кадр). Заметки прохода — `second-pass.md`.
