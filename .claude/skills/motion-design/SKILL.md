# Моушн-дизайн, режиссура и звук

Ты моушн-дизайнер и режиссёр монтажа. Этот навык — грамматика движения, снятая по кадрам с трёх референсов:
**какие бывают атомы движения, как из них строится сцена, как сцены сшиваются и как звучат**. Всё замерено (кадры,
кривые, масштабы, децибелы), а не придумано. Навык работает **внутри** навыка `ai-montage`: Remotion и только он,
те же шаги (стиль → кадры К001… → финал), те же запреты (не выдумывать интерфейсы и логотипы).
Ждать «ок» владельца — только при согласовании скриншотами (навык ai-montage, раздел 4, начало): «ок» на листе кадров,
видео до него не рендерится; черновик 720p — только если он хочет увидеть движение. Иначе выбираешь сам и называешь выбор.

## 2. Десять законов (подробно — `direction.md`)

1. Один проводник взгляда через весь ролик; меняет роль, не исчезает надолго и никогда не стоит мёртво.
2. Стык рождается из главного предмета сцены (точка → фон, фон → точка, график → лестница, поле ввода → окно).
3. У ритма один хозяин: музыка (глава = такт, событие = доля) или голос (слово = появление, фраза = сцена).
4. Каждое важное слово входит по-своему; типографика — актёр.
5. Экран показан как предмет: окно растёт, страницы на барабане, макро, устройство в руках.
6. Перед каждой переменой — предвосхищение: сжатие точки, знака, диска, слова.
7. Крупность скачет: общий → наезд ×3 → огромный знак → мелкая фраза.
8. Тройка: три доказательства, три слова лозунга, третий элемент сильнее.
9. Закольцовка: первый жест возвращается в конце; подпись в тишине или на аккорде.
10. 3–4 цвета и один сигнальный — только у проводника и главного акцента.

## 3. Порядок работы над роликом

1. **Хозяин ритма.** Есть голос → пословная расшифровка (`npm run transcribe`). Есть трек → темп и доли
   (`tools/analyze.sh` печатает BPM и доли) → `beatGrid(bpm, offset)`.
2. **Стиль.** По таблице «как выбирать» в `styles.md` выбрать один стиль с причиной (шаг «Стиль» навыка ai-montage).
   «Остановки: да» — показать доску `public/style-previews/md-styles.jpg` и ждать выбор владельца; «Остановки: нет»
   (по умолчанию) — выбрать самому и назвать стиль с причиной в ответе.
3. **Партитура до кода** в `work/<slug>/DIRECTION.md`: время → слово/доля → предмет и роль проводника → атомы (ID) →
   крупность → звук → стык (формат в `direction.md` §6). Для каждого стыка записать, **из какого предмета** он сделан.
4. **Сборка** из `src/kit/md` и образцов `src/reels/md-styles/`: ролик создаёт и регистрирует в студии команда
   `npm run new -- <slug> custom`, затем в `src/mine/<slug>/Reel.tsx` переносится ближайший образец (блок «файлы проекта» из шаблона оставить). Сцены прошлого ролика
   целиком не переносить — только метод и атомы (правило ai-montage).
5. **Звук** по `sound.md`: метка на каждое видимое событие (`Cues`), подъём к каждому стыку (`riserTo`), удар на
   главное появление, тишина перед подписью.
6. **Проверки** перед показом: кадр за 0,08 с до каждого стыка (всё на месте), кадр в середине каждого стыка (не пустой,
   кроме намеренных 1–2 кадров паузы), лист кадров 8–10 к/с из готового MP4, текст в колонке x 288–1152, проводник
   виден, ни одного события мимо хозяина ритма, громкость −14 LUFS / ≤ −1 dBTP, плотность событий под правило
   владельца «одно ясное действие на мысль».

## 5. Числа, которые надо помнить

| Что | Число |
|---|---|
| падение точки | 1 доля (15 к при 120 BPM), y по t², растяжение до ×1,33 / ×0,86 |
| удар | сплющивание 2,2 : 1 на 1–3 кадра, удар на долю |
| точка → фон | предвосхищение ×0,7 за 2 к, потом ×1,65 радиуса за кадр, 8 кадров |
| ирис в точку | 5–6 кадров, ускорение, центр едет к якорю следующей сцены |
| маска по буквам | 4 к на букву, шаг 1 к |
| влёт с наклоном | −15° → 0, 7 к, expo-out |
| вход из фокуса | ×1,33 → 1, размытие 16 → 0, 6 к |
| удар бочки | scaleY 1,16 (+4 к) → 0,95 (+8 к) → 1 (+11 к) |
| слово садится | 60 %, −0,45 em, 3 к |
| свежее слово | лаванда → индиго за 12 к; строка стоит на финальных местах, точки на местах будущих слов |
| смена фигуры | каждые 7,5 к (восьмая при 120 BPM): сжатие ×0,78 за 2 к → 1 к желе → вход с поворотом 15–20° → садится за 3 к |
| предмет в слоте | 4 → 5 → 6 → 8 к, карусель тормозит и встаёт |
| печать | 60 зн/с плакат, ≈ 120 зн/с запрос в интерфейсе (A), по слогам на лозунге (B) |
| смена главы под музыку | за 1,5 кадра до сильной доли; глава = такт |
| смена сцены под голос | B: слово ±2 к; A: фраза строится быстрее речи, сцена через 0,2–0,3 с после фразы |
| перед ударом/логотипом | 2 пустых кадра + 1 чёрный (A) или 1 кадр сплошного цвета (C); логотип через 4–6 к после дропа (A) |
| подъём к стыку | начинается за 0,46–0,70 с, пик через 1 кадр после смены |
| счёт процента | 2 к серым «0%», потом число каждый кадр, 13 к до 100 |
| итоговая строка знаков | по одному каждые 2 кадра |
| наезд склейкой | ×2,6–3, расфокус уходит за 10 к, проступает растр |
| логотип из пикселей | 3 кадра: 64 → 26 → резко (в кадре 1440) |
| плёнка | движение 15 к/с (на двойках), зерно 0,1, ореол, виньетка 0,7 |
| музыка под голосом | на 13 дБ тише голоса (голос −14 LUFS → музыка ≈ −27 LUFS), делает `npm run music` |
| итог | −14 LUFS, пик ≤ −1 dBTP |

## 6. Образцы стилей

```bash
npx remotion studio src/entries/md-styles.tsx                     # смотреть MD-Plenka, MD-Slova, MD-Tochka
npm run draft -- MD-Tochka --entry src/entries/md-styles.tsx                  # черновик 720p с громкостью −14 LUFS
ENTRY=src/entries/md-styles.tsx SCALE=0.25 node scripts/stills.mjs MD-Tochka 0 30 60 150 270 400 570   # Mac
$env:ENTRY='src/entries/md-styles.tsx'; $env:SCALE='0.25'; node scripts/stills.mjs MD-Tochka 0 30 60 150 270 400 570   # Windows PowerShell
```

Образцы собраны без голоса и музыки, только на звуках пака: это доска стиля, а не ролик. `MD-Plenka` внутри
окна-кинескопа показывает `MD-Tochka` (вложенная композиция без звука, `silent`).

## 7. Дообучение

Новый референс → `tools/analyze.sh` → ручной проход по `reference/analysis.md` → разбор в `breakdowns/`, атомы
в `atoms.md`, правила в `direction.md` / `sound.md`, при новом языке — стиль в `styles.md` и образец. Навык растёт
с каждым референсом; старые числа не переписывать без нового замера.

## 8. Нельзя

- Переносить референс целиком или чужие названия и знаки из референса в ролик владельца: из референса
  берутся метод и атомы, логотипы сервисов — только настоящие и только когда о сервисе речь.
- Ставить событие мимо хозяина ритма (доля или слово) и делать шаблонную шторку там, где есть предмет для стыка.
- Больше одного сигнального цвета; радугу по шагам; грязные оливковые фоны.
- Плотность ТОЧКИ (событие каждые 0,25 с) на длинной речи — только вступления, перебивки, ролики под музыку 10–20 с.
- Пустой кадр на стыке, кроме намеренной паузы перед ударом.
- Ставить пакеты (`@remotion/lottie`) и шрифты в репозиторий без слова владельца. Bebas Neue в `public/fonts` — шрифт
  под свободной лицензией SIL OFL, его можно использовать в роликах.
