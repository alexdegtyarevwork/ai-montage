# SVG-иконки, знаки и Lottie

## Что делают иконки в референсах

| | Иконки и знаки | Как двигаются |
|---|---|---|
| C | шесть геометрических знаков одной толщины и веса (точка, квадрат, кольцо, прицел, искра, лучи), сплошная заливка; строка мини-знаков как оглавление | знак перетекает в знак на восьмые доли (6 кадров, перелёт), квадрат доворачивается с 15°; итоговая строка выпрыгивает по одному с шагом 0,1 с |
| B | линейные иконки (контур ≈ 1,8 на 24, скруглённые концы) гроздьями по 3; пластилиновые 3D-предметы; глянцевое кольцо-знак | слово подпрыгивает и превращается в гроздь; иконки сменяются каждые 6 кадров; предметы выпрыгивают по кругу с перелётом и поворотом |
| A | знак-звёздочка из лучей со скруглёнными концами, светится | собирается из пикселей за 3 кадра, медленно вращается (≈ 0,4°/кадр), «прогорает» перед сменой |

Правила, которые из этого следуют:
1. **Одна система:** у всех иконок ролика одна толщина линии, одни скругления, один вес. Знаки бренда — заливкой,
   служебные иконки — контуром.
2. **Иконка заменяет слово, а не украшает его** (B: «Every» → три иконки дел). Иконка без смысла в речи — лишняя.
3. **Гроздь из трёх** лучше одной: показывает разнообразие («что угодно»).
4. **Вход и жизнь:** дорисовка контура 8–12 кадров или выпрыгивание 6–8 кадров с перелётом (`EASE.back`), шаг между
   иконками 2 кадра; в удержании — медленное вращение, пульс или смена содержимого, иначе иконка «умирает».

## Что есть в коде (`src/kit/md/signs.tsx`)

- `MorphSign` — последовательность знаков с морфингом. Внешний контур каждого знака задан в полярных координатах
  на 144 точках, поэтому любые два знака перетекают без рывков; кольцо и прицел — дырка и засечки отдельными параметрами.
  Добавить знак = дописать функцию радиуса `r(θ)` в `outer()` и запись в `SHAPES`.
- `SignGlyph` — мини-знак для строки-оглавления.
- `ICONS` + `Icon` — свои линейные иконки 24×24 (calendar, clock, bolt, chat, camera, laptop, headphones, car, shield,
  heart, play, check, search, spark, music, pen, film, cursor). `draw` 0…1 — дорисовка контура через `evolvePath`
  (`@remotion/paths`), это тот же приём, что trim path в Lottie.
- `PopIn` — выпрыгивание с перелётом и поворотом для иконок и предметов.
- В образцах: `RingMark` (глянцевое кольцо, `Slova.tsx`), `Spark` (звёздочка, `Plenka.tsx`).

Свои иконки рисуются своими контурами. Чужие наборы (Lucide, Material, Font Awesome) — только с их лицензией и
указанием источника; логотипы сервисов — только настоящие из `public/brand` (правило ai-montage).

## Lottie: что это и как с ним работать здесь

Lottie — формат векторной анимации: дизайнер анимирует в After Effects, плагин Bodymovin выгружает JSON, а плеер
рисует его по кадрам. `airbnb/lottie-android` — плеер этого формата для Android; есть такие же
для iOS, React Native и веба (`lottie-web`). Один и тот же JSON играется везде — иконку, собранную для ролика,
можно отдать в приложение без переделки.

В нашем конвейере (только Remotion) роль плеера играет **`@remotion/lottie`** поверх `lottie-web`: Remotion сам
ставит анимацию на нужный кадр, поэтому рендер детерминированный и можно перематывать.

```bash
npm i @remotion/lottie@4.0.526 lottie-web
```

(версия строго как у `remotion` в `package.json`; пакет пока **не установлен** — ставить с согласия владельца)

```tsx
import {Lottie, getLottieMetadata} from '@remotion/lottie';
import data from '../../public/lottie/check.json'; // JSON, не .lottie
// <Sequence from={…}> задаёт момент старта; playbackRate ускоряет; loop — для фоновых
<Lottie animationData={data} playbackRate={1} style={{width: 240, height: 240}} />
// getLottieMetadata(data) → {durationInFrames, fps, width, height} — чтобы подогнать длину Sequence
```

- `animationData` держать неизменным объектом (импорт или `useMemo`), иначе анимация перезапускается.
- `.lottie` (dotLottie) — это zip: распаковать и взять `animations/*.json`. Картинки внутри Lottie — через `assetsPath`.
- В вебе не всё из After Effects работает: эффекты слоёв (размытие, свечение), выражения, merge paths — проверять
  в плеере до монтажа. Свечение и размытие лучше добавить снаружи CSS-фильтром на обёртке.
- Источники: свой экспорт из After Effects (Bodymovin), библиотеки готовых Lottie (проверять лицензию каждого файла),
  или JSON, написанный кодом (ниже).

### Lottie руками: скелет, который можно генерировать

Точка выпрыгивает с пружиной стиля ТОЧКА (cubic-bezier(.34,1.56,.64,1)) за 12 кадров:

```json
{"v":"5.7.4","fr":30,"ip":0,"op":30,"w":200,"h":200,"nm":"dot-pop","ddd":0,"assets":[],
 "layers":[{"ddd":0,"ind":1,"ty":4,"nm":"dot","sr":1,"ao":0,"ip":0,"op":30,"st":0,"bm":0,
  "ks":{"o":{"a":0,"k":100},"r":{"a":0,"k":0},"p":{"a":0,"k":[100,100,0]},"a":{"a":0,"k":[0,0,0]},
        "s":{"a":1,"k":[{"t":0,"s":[0,0,100],"o":{"x":[0.34],"y":[1.56]},"i":{"x":[0.64],"y":[1]}},{"t":12,"s":[100,100,100]}]}},
  "shapes":[{"ty":"gr","it":[
    {"ty":"el","p":{"a":0,"k":[0,0]},"s":{"a":0,"k":[60,60]}},
    {"ty":"fl","c":{"a":0,"k":[0.871,0.306,0.173,1]},"o":{"a":0,"k":100}},
    {"ty":"tr","p":{"a":0,"k":[0,0]},"a":{"a":0,"k":[0,0]},"s":{"a":0,"k":[100,100]},"r":{"a":0,"k":0},"o":{"a":0,"k":100}}]}]}]}
```

- `fr` — частота, `ip/op` — первый и последний кадр, `ks` — трансформ слоя (o прозрачность, r поворот, p позиция,
  a якорь, s масштаб в %), анимированное свойство `{"a":1,"k":[ключи]}`.
- Ключ: `t` — кадр, `s` — значение; кривая отрезка хранится в начальном ключе: `o` — первая ручка, `i` — вторая.
  cubic-bezier(x1,y1,x2,y2) → `"o":{"x":[x1],"y":[y1]},"i":{"x":[x2],"y":[y2]}`.
- Фигуры в группе `gr`: `el` эллипс, `rc` прямоугольник, `sh` контур (`v` вершины, `i`/`o` ручки), `fl` заливка
  (цвет 0…1), `st` обводка (`w` толщина, `lc`/`lj` концы и стыки), `tm` trim path (`s`/`e` 0…100 — дорисовка), `tr`
  трансформ группы (обязателен последним).
- Сгенерированный JSON проверять в плеере (студия Remotion с `@remotion/lottie` или веб-просмотрщик LottieFiles) до
  того, как ставить в ролик.

### Иконка набора → Lottie одной командой (проверено в lottie-web 5.12)

```bash
node .claude/skills/motion-design/tools/svg2lottie.mjs clock public/lottie/clock.json --color "#DE4E2C" --stroke 2 --size 512
node .claude/skills/motion-design/tools/svg2lottie.mjs "M5 12l5 5 9-10" public/lottie/check.json --draw 12 --pop 8
```

Скрипт берёт контур из `ICONS` (`src/kit/md/signs.tsx`) или любой путь 24×24, переводит его в вершины Lottie
(`@remotion/paths` → кубические Безье) и анимирует: дорисовка контура trim path за `--draw` кадров (expo-out) +
выпрыгивание масштабом 0 → 100 % и поворотом −10° → 0 за `--pop` кадров (cubic-bezier(.34,1.56,.64,1)), потом
`--hold` кадров удержания. Один и тот же файл открывается в lottie-android, lottie-ios, вебе и
`@remotion/lottie` — иконку из ролика можно сразу отдать в приложение. `--fill` добавляет заливку для знаков.

### Когда что брать

| Задача | Чем |
|---|---|
| знак бренда, морфинг фигур, иконка-слово, всё, что зависит от речи и доли | свой SVG в Remotion (`MorphSign`, `Icon`, `PopIn`) — точный тайминг кадр в кадр |
| сложная персонажная или многослойная анимация от дизайнера | Lottie из After Effects через `@remotion/lottie` |
| иконка, которую потом надо отдать в приложение | Lottie (тот же JSON для Android/iOS/веба) |
| UI-микроанимация в ролике (галочка, загрузка, лайк) | готовый Lottie с проверенной лицензией или свой SVG |
