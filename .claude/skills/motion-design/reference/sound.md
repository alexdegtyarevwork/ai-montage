# Саунд-дизайн: звук как часть движения

Замеры: громкость EBU R128 (ffmpeg ebur128), дорожки разделены htdemucs (голос / ударные / бас / прочее), события —
по спектрограммам `breakdowns/img/C-sound.jpg`, `A-music.jpg`, `B-music.jpg`. Все три ролика сведены в **−14 LUFS**,
пик −1 dBTP (A перегружен до +0,2 — так делать не надо).

## Три модели звука

| | C «одна точка» | A «тёплая плёнка» | B «слова и иконки» |
|---|---|---|---|
| Хозяин ритма | музыка 120 BPM | голос | голос |
| Музыка | электронный трек, бочка на каждую долю с 2,5 с, хэты на восьмые | вступление без ударных → дроп → грув ≈ 100 BPM → уход | мягкий грув ≈ 112 BPM |
| Уровень музыки | одна дорожка, LRA 2 | плотный трейлерный микс, музыка почти вровень с голосом (−18 против −20 dB RMS) | на 12–15 dB **ниже** голоса (−31 против −20) |
| Отдельные эффекты | нет: события озвучены самой музыкой (подъёмы, ноты, глайды) | почти нет: подъём + дроп на логотипе | много коротких тональных UI-звуков на каждое микрособытие |
| Конец | аккорд-разрешение без ударных, «дзинь» на пульс | музыка уходит фильтром за 1,5 с до конца, подпись в тишине | музыка дотягивает, затемнение 0,6 с |

Это замеры референсов. В наших роликах музыка под голосом всегда **на 13 дБ тише голоса** (голос −14 LUFS → музыка
≈ −27 LUFS); подложку готовит `npm run music` (`ПРАВИЛА/5 Звук.md`).

## Правила, которые повторяются

1. **Одно видимое событие — один звук, пик звука на кадре события.** Набор: метка `[кадр, файл, громкость]` ставится
   пиком (`Cues` в `src/kit/md/sound.tsx` сам вычитает время до пика по `sfx-meta.json`).
2. **Подъём к стыку.** Шумовой или тональный подъём начинается за 0,46–0,70 с до смены сцены, пик — через 1 кадр
   после смены (C, замер по всем шести главам: +0,03 с); A — 4,6–4,81 перед дропом; B — 13,3–13,8 перед знаком.
   `riserTo(кадр)` ставит пик на кадр смены.
3. **Дроп = главное появление.** Удар музыки (бочка + бас, +12 dB) у логотипа или имени продукта; голос в эти
   0,3–0,5 с молчит. Замер A: удар 4,81, логотип 5,00 — **звук на 4–6 кадров раньше картинки**, между ними искра и
   один чёрный кадр. У C наоборот: картинка на 1–2 кадра раньше доли. Оба варианта рабочие, нельзя только «вразнобой».
4. **Звук рисует движение.** Глиссандо вверх, пока точка рисует растущую кривую; нисходящий глайд, пока точка летит по
   орбите к финалу; одна нота на каждую смену фигуры (C). Если своей музыки нет — тональные блипы пака по высоте вверх.
5. **Музыка уступает голосу.** Вступление без голоса — музыка громко (B −20 dB RMS); на первом слове музыка опускается
   и живёт под голосом на 13 дБ тише него (голос −14 LUFS → музыка ≈ −27 LUFS). Плотный микс A не используем.
6. **Тишина перед подписью.** Последняя фраза бренда — без музыки (A «This is Claude.») или на аккорде без ударных (C).
   Музыка уходит не простым затуханием, а **фильтром вниз**: A 23,3–24,5 — уровень −17 dB за ≈ 1 с, центр спектра
   1,66 → 0,72 кГц.
6а. **Переходный звук проходит сквозь склейку.** B (16 склеек): звук стартует от −0,35 до +0,13 с относительно склейки,
   пик через 0,1–0,5 с после неё. Ставить свист так, чтобы склейка пришлась на его нарастание, а не на хвост.
6б. **Панорамой не двигают.** Все эффекты B по центру (±0,3 dB); ширина стерео — от музыки, не от эффектов.
7. **Тональные UI-звуки, не шумовые.** B: короткие «блипы» в тональности трека на превращения слов, смену иконок, клик,
   шаг в приложении, писк сканера; громкость намного ниже голоса. Шумовые трескучие нарезки на стыках читаются как
   бьющееся стекло (правило навыка ai-montage).
8. **Фоновое движение — тишина.** Комета на орбите, дымка, свечение, медленный наезд звука не получают.

Звук для ролика выбирается только по каталогу `public/sfx/pack/КАТАЛОГ.md`, путь к файлу — из каталога. Имена ниже —
файлы `public/sfx/<имя>.wav`; `sheet/…` — фирменные звуки стиля 15 ЛИСТ (`public/sfx/sheet/`, тайминги в
`src/kit/sheetSfx.ts`).

## Музыка

Музыка набора — 23 трека в `engine/public/music`, каталог с темпом и окраской — `engine/public/music/КАТАЛОГ.md`.
Своя музыка ученика (папка «Музыка» или чат) главнее. Для стиля ТОЧКА нужен трек с ровной долей (110–128 BPM) и ясными подъёмами;
темп трека задаёт `beatGrid(bpm, offset)`, сцены ставятся на `bar(n)` и `cut(n)`. Сначала берётся трек и
снимается его сетка (`tools/analyze.sh` печатает BPM и доли), потом монтаж — не наоборот. Если трека нет, звук
строится только из пака (как в образцах стилей) — тогда подъёмы и удары несут ритм сами.

## Сведение

- Голос — основа: ≈ −20 dB RMS на активных местах, сухой, пик-фактор ≈ 14 dB (B: умеренная компрессия); эффекты —
  громкость из каталога пака (слой `src/sound.tsx`, `ПРАВИЛА/5 Звук.md`), без множителей.
- Итог: −14 LUFS интегрально, пик ≤ −1 dBTP (делает `npm run render`, отдельно — `npm run master`), LRA 2–4.
- Ролик только из эффектов (образцы стилей) до −14 LUFS не дотягивается без перегруза — это нормально для черновика.
