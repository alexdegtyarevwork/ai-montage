# Словарь микроатомов движения

Каждый атом снят с референса по кадрам (30 fps) и замерен: кадры, кривая, масштаб. «Код» — компонент или функция из
`src/kit/md` (время в кадрах 30 fps, в 60-кадровой композиции числа те же). Источник: A — «тёплая плёнка»
(`breakdowns/A-…`), B — «слова и иконки», C — «одна точка». Размеры даны в кадре референса; для 2K 1440×2560
переводить через `reference/reels.md`.

Кривые набора: `EASE.back` = cubic-bezier(.34,1.56,.64,1) (перелёт до 1,10) · `EASE.out` = (.16,1,.3,1) expo-out ·
`EASE.in` = (.7,0,.84,0) expo-in · `EASE.inOut` = (.65,0,.35,1) · `EASE.gravity` = t².
