# Новые стили монтажа 16–18 и два рецепта

Стили построены на законах `direction.md` и атомах `atoms.md`, не на копировании референсов: у каждого своя
палитра, свой проводник и свой язык стыков. Стили 16–18 входят в основной список стилей 1–21 (`ПРАВИЛА/6 Стили.md`,
`patterns/README.md`); рецепты ИСКРА-СПИКЕР и ЭКРАН-ПРЕДМЕТ — без номера и без образца. Образцы 16–18 собраны и отрендерены
(`src/reels/md-styles/`, точка входа `src/entries/md-styles.tsx`, доска `public/style-previews/md-styles.jpg`).

Кадр 1440×2560, частота финала как в исходнике (без исходника видео — 30 к/с), время в коде — кадры 30 fps. Смысловая
колонка x 288–1152 (центр 720, справа рейка Instagram), главное в y 360–1664. Субтитры не мельче 64 px в кадре 1440
(48 px при ширине 1080); служебные подписи стиля могут быть мельче, от 44 px.

## 16 ПЛЁНКА — тёплая тьма, искра-проводник (из A)

**Когда:** показать результат нейросети или продукт «как кино»: запуск, «смотри, что получилось», трейлер курса,
кейс. Хорошо с голосом без лица (формат 5) и с половиной экрана (формат 1: спикер снизу, плёнка сверху).

- **Палитра:** фон `#0E0D09`, свечение `#C2461F` / `#8E2A14` / `#E0603A`, текст `#F1E6D2`, сигнал `#FF7A3D`.
- **Шрифт:** SF Pro Display Light курсивом (300, наклон синтетический), крупные планы 200–240 px, фраза 84–92 px.
- **Проводник:** оранжевая искра: ведёт слова (P7) → полутоновый диск на наезде (P11) → логотип-звёздочка → комета,
  пишущая название (P8) → чип → курсор → лупа (P9) → каретка (P10).
- **Слова:** садятся на строку (T6), призрак следующего слова и «дышащая» строка (T25, T26), фраза строится быстрее
  голоса и ждёт его; акцент цветом + рукописное подчёркивание (T21); связка «знак + имя» всегда по центру (T27).
- **Проводник никогда не стоит:** дрейфует в удержании (P14), патрулирует край кадра (P16), после темноты всплывает
  с приближением (P17).
- **Стыки:** наезд ×2,6–3 склейкой с расфокусом и растром (S19); уход «текст вверх — точка вниз» (S10) → 2 пустых
  кадра → искра снизу → 1 чёрный кадр (S11) → логотип из пикселей на дропе (S12); световая полоса стирает слово (S9) →
  чип в поле ввода (S8) → поле ввода растёт в окно-кинескоп с результатом (S7); склейки внутри постоянной рамки (S18);
  барабан страниц (K4), макро с переводом фокуса (K3); смаз-уход (S13).
- **Фактура обязательно:** на двойках (F1), зерно, ореол, виньетка, живое свечение снизу; хроматизм только на крупных планах.
- **Звук:** тихое вступление → подъём → дроп на логотипе → грув → музыка уходит до подписи; почти без UI-звуков.
- **Нельзя:** белые фоны, плоская запись экрана без рамки, плавное движение без двоек (ломает плёнку), больше одного сигнального цвета.
- **Образец:** `src/reels/md-styles/Plenka.tsx`, композиция `MD-Plenka` (11,4 с).

## 17 СЛОВА — речь пишет экран (из B)

**Когда:** объяснение продукта, привычки, «зачем это тебе»; озвучка без лица (формат 5) или спикер в карточке внизу
(формат 4) с белой зоной графики сверху. Самый «говорящий» стиль: держит длинную речь без усталости.

- **Палитра:** лист `#FCFCFE`, дымка `#B6A1F6` / `#C9B8FA`, текст `#200B44`, свежее слово `#A68BEA`, акцент `#8B5CF6`,
  тёплый градиент вступления `#B79CF6 → #E7D9F4 → #F7DCCB`.
- **Шрифт:** Manrope 600 (геометрический гротеск), фраза 100–120 px, разборка слова 190 px, знак 150 px 800.
- **Проводник:** знак-кольцо (I5) и курсор (U5); точки-места будущих слов (P13).
- **Слова:** фраза по словам, строка сразу стоит на финальных местах с точками на местах будущих слов (P13, T8), свежее
  слово светлое → тёмное, уголки видоискателя на месте следующего слова (T9), штрихи-разрезы (T28), слово → гроздь
  иконок, иконки меняются по одной (T10), грозди меняются местами по орбите (T29), предмет-слот внутри фразы (T11), разборка слова с направляющими (T12), перестройка
  строки (T13), тройка нарастанием с уходом стиранием слева (T20), надпись выезжает из-за знака конвейером (T22) и финальная шторка
  с перецентровкой (T22b), маленький текст в раме из предметов (T31).
- **Стыки:** уход в белое засветкой (S14), отъезд «это экран» (S15), сдвиг к живой съёмке (S16), знак держится —
  фон меняется (S17), буквы съезжаются → склейка на знак (S21), рывок-наезд на кнопку (S20).
- **Объекты:** пластилиновые 3D-предметы (`public/objects/*.webp`) выпрыгивают по кругу (I3), коллаж-кольцо (K8),
  созвездие вокруг телефона (K10), линейные иконки (I4).
- **Звук:** музыка громко до голоса, потом на 13 дБ тише голоса; тональные блипы на каждое превращение слова, тики на смену
  предмета, подъём + «искра» на знак.
- **Нельзя:** тёмные фоны в текстовых сценах, капс, больше одной фразы на экране, лесенка из пяти и более предметов
  подряд (правило владельца: связанное появляется вместе).
- **Образец:** `src/reels/md-styles/Slova.tsx`, композиция `MD-Slova` (11,5 с).

## 18 ТОЧКА — плакат в такт, одна точка (из C)

**Когда:** вступление серии, анонс, итог, ролик без слов под музыку 10–20 с, «шоурил» умений. Со спикером — только
главы-перебивки между частями (2 с на главу), не весь ролик.

- **Палитра:** чернила `#0F100D`, бумага `#EFEBDF`, сигнал `#DE4E2C`, линии `#34342F`, вторичный `#8F8C84`.
  Фоны глав чередуются: чёрный → красный → бумага → чёрный → бумага.
- **Шрифт:** сверхузкий гротеск капсом (Bebas Neue Bold с кириллицей; по референсу Druk), 300–360 px; HUD и подписи —
  SF Pro Display 600 капсом с разрядкой 0,14 em, 44 px; знак-подпись — Manrope 800 строчными.
- **Предвосхищение везде:** знак сжимается перед каждым морфингом и входит с поворотом (I1), диск сжимается перед
  заливкой кадра, точка — перед прыжком (P5).
- **Проводник:** красная точка: падает (P1) → удар (P2) → отскок в точку после слова (P3, P4) → предвосхищение (P5) →
  раздувается в фон (S1) → ирис в точку (S2) → комета вокруг знаков (P6) → бегунок кривой (H3) → удар в подписи → пульс (P12).
- **Глава = такт** (`beatGrid(bpm)`, 2 с при 120 BPM), смена за 1,5 кадра до доли, HUD с таймкодом и главами (H1).
- **Слова:** три входа (T1/T2, T3, T4), удар бочки (T5), эхо-экструзия (T17), барабан подписи (T18), печать 60 зн/с.
- **Стыки:** только из предмета: S1, S2, S3, S4, S5, S6.
- **Звук:** музыка-хозяин; подъём на последней доле каждого такта; удар на падение и подпись; тики на смену фигур.
- **Нельзя:** градиенты, тени, стекло, больше трёх цветов, событие мимо доли, глава длиннее такта без причины.
- **Образец:** `src/reels/md-styles/Tochka.tsx`, композиция `MD-Tochka` (11,6 с).

## Рецепт ИСКРА-СПИКЕР — точка между спикером и графикой (гибрид, рецепт)

Формат 4 навыка ai-montage (спикер в карточке внизу, графика сверху) + проводник из ТОЧКИ + слова из СЛОВ.

- Красная (или фирменная) точка живёт на карточке спикера как индикатор «в эфире» и **уходит в графику на каждом новом
  смысловом блоке**: падает в верхнюю зону, становится точкой после ключевого слова, раздувается в фон блока (S1),
  на конце блока возвращается в карточку ирисом (S2).
- Ключевые фразы — СЛОВА (T8) над карточкой; крупные цифры и названия — ТОЧКА-плакат (T1–T4); перебивки глав — HUD с
  настоящим таймкодом.
- Ритм — голос: слово ±2 кадра, блок = мысль; точка двигается только на ударных словах (не чаще раза в 1,2 с).
- Палитра от записи владельца (правило: фон гармонирует с картинкой, Apple-монохром + один акцент).

## Рецепт ЭКРАН-ПРЕДМЕТ — результат нейросети как вещь (гибрид, рецепт)

Для роликов «я попросил ИИ — вот что вышло»: запрос → результат → ещё результат.

- Поле запроса печатается (T14) → чип модели падает в поле (S8) → поле растёт в окно результата (S7) → склейки
  результатов внутри постоянной рамки (S18) → отъезд: окно оказывается экраном телефона или монитора в руках/комнате
  (S15) → барабан из нескольких результатов (K4) → макро на детали с переводом фокуса (K3).
- Фактура по выбору: тёплая плёнка (16) для «кино», светлый лист (17) для «продукта».
- Настоящие записи экрана и логотипы сервисов обязательны (правило ai-montage: не выдумывать интерфейсы).

## Как выбирать

| Ролик | Стиль |
|---|---|
| спикер объясняет продукт или идею, 30–60 с | 17 СЛОВА или рецепт ИСКРА-СПИКЕР |
| показываю, что сделала нейросеть | рецепт ЭКРАН-ПРЕДМЕТ на фактуре 16 или 17 |
| запуск, анонс, трейлер, «вау» | 16 ПЛЁНКА |
| вступление серии, итог, без слов под музыку, 10–20 с | 18 ТОЧКА |
| перебивки глав внутри длинного ролика | главы 18 ТОЧКА по 2 с |

Стиль советует агент (навык ai-montage, раздел 4, шаг 6). «Остановки: да» — выбирает владелец; «Остановки: нет»
(по умолчанию) — агент выбирает сам и называет выбор в ответе. Владелец уже отклонял: тусклые оливковые
фоны, радугу по шагам, сверхдинамику без пауз — проверять каждый стиль на эти три ошибки.
