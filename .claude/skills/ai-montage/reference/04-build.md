# Сборка ролика подробно (все команды — в папке engine)

## 1. Проект и материалы

```
npm run new -- <slug> <СТИЛЬ|custom|geroy>  # slug латиницей и цифрами: trend-gas-station, 5-oshibok
```
Создаёт `work/<slug>/` (brief.json, DIRECTION.md, PUBLISH.md, reference-profile.md), `public/work/<slug>/` и код ролика.
Запись ученика: `npm run prep -- "../Видео/<файл>" <slug>` → `speaker.mp4` 1440×2560 и `voice.wav`. Нарезка дублей:
`npm run takes -- <slug>` → `npm run cut -- <slug> <номера>` (или `none`) → `speaker-cut.mp4`, `voice-cut.wav`,
`cut_preview.mp4`. Источник каждого стороннего файла (сток Pixabay или Pexels, Wikimedia: автор, ссылка) записать в
`work/<slug>/ASSET_SOURCES.md`, для ученика — `источники.txt` в папке результата.

## 2. Расшифровка по словам

```
npm run transcribe -- public/work/<slug>/voice-cut.wav work/<slug>/words.json
```
- whisper.cpp и модель medium (~1,5 ГБ) уже в `.whisper/` после установки (`npm run setup`). Для русского только многоязычные модели.
- Правь **только написание**: названия сервисов (Claude, GitHub, CapCut), ё, кавычки, склейку разорванных слов.
  Тайминги не трогать: субтитры и все события ролика привязаны к ним.
- Выведи слова с номерами и временем: по ним ставятся стыки, события и звуки («на слове „перебить“ 12,63 с»).

## 3. Карта монтажа до кода (`work/<slug>/DIRECTION.md`)

Таблица на каждый смысловой блок: **время → фон → что на экране → стык и почему → где спикер**. Правила:
- Своя архитектура под этот текст: главный предмет первых секунд, форма схемы (цепочка, развилка, до/после, воронка), вставки,
  набор стыков, цветовые зоны. Из образцов берётся метод, не набор сцен.
- Фон меняется на каждом блоке, 5–7 раз в минуту. Цветовые зоны по смыслу, палитра одна на ролик.
- Настоящие записи ставятся на точную фразу, где их смысл. Записи экрана почти на всю ширину, с кликами.
- Каждый стык обоснован фразой: влёт в окно «вот оно», рывок контраст, вспышка раскрытие результата, сжатие в узел
  вход в схему, уход в тёмное призыв.
- Кадр 0 уже полный: человек и первые слова или главный предмет. Огромная фраза-хук — только если её задал стиль или
  попросил ученик (`reference/02-script.md`).
«Остановки: да» — показать карту владельцу коротко (таблицей) и ждать «ок». «Остановки: нет» (по умолчанию) — не ждать:
работать дальше и коротко назвать план в ответе.

## 4А. Сборка на движке стилей (`src/mine/<slug>/project.ts`, файл создаёт `npm run new -- <slug> <СТИЛЬ>`)

Стили: `CANVAS` (1 КАНВАС), `LIQUID` (2 СТЕКЛО), `PRISM`, `ORBIT`, `TRACE`, `PULSE`, `GLASS`, `PORTRAIT`, `APPLE`, `PODCAST`, `EXPERT` (5–13).
Запись, голос, слова, длительность и частоту подставляет блок «файлы проекта» (его переписывают `prep`, `cut` и `transcribe`) —
агент заполняет только `blocks` и `plan`:

```ts
export const STYLE = 'PRISM';
// >>> файлы проекта … // <<<   (не трогать: LINK = {fps, duration, words, speaker, voice})
export const PROJECT: ProjectData = {
  ...DEMO, ...LINK,
  blocks: [
    {kind: 'hook', id: 'hook', label: '01', at: 0, lines: ['Джарвис', 'у тебя дома'], object: 'mic'},
    {kind: 'list', id: 'how', label: '02', at: 9.1, title: 'Как работает', items: ['…', '…', '…'], ticks: [10.2, 11.0, 11.8]},
    {kind: 'stat', id: 'num', label: '03', at: 15.0, value: 223, suffix: ' звезды', caption: 'на GitHub', countAt: 15.3},
    {kind: 'logos', id: 'stack', label: '04', at: 20.9, title: 'Что нужно', logos: ['claude', 'github']},
    {kind: 'flow', id: 'scheme', label: '05', at: 25.0, title: 'Схема', nodes: [{label: 'браузер'}, {label: 'Claude Code', logo: 'claude'}]},
    {kind: 'cta', id: 'cta', label: '06', at: 46.7, note: 'Напиши в комментариях', word: 'ДЖАРВИС', typeAt: 47.0},
  ],
  // speaker и voice уже в LINK; поправить можно только положение лица: speaker: {...LINK.speaker!, headY: 1075}
  plan: [{at: 25.0, to: 'compact'}, {at: 46.7, to: 'base'}],
  sfx: true,
};
```
`at`, `ticks`, `countAt`, `typeAt` берутся из времени слов. Логотипы: имена файлов `public/brand/*.svg`. Состояния окна
спикера в `plan` и типы блоков смотреть в `src/template/Speaker.tsx` и `src/template/blocks.tsx`. У блока можно
указать `tone: 'light'` (светлая сцена), `object` (3D-предмет из `public/objects`), `shot` (снимок сервиса для EXPERT).

## 4Б. Свой ролик (`src/mine/<slug>/Reel.tsx`, шаблон и образцы)

- Шаблон `custom`: `CHANGES` (когда спикер уходит в угол), `BLOCKS` (смысловые блоки с фоном), `SFX`, `FACE`.
  Шаблон `geroy` (стиль 21 ИСТОРИЯ С ГЕРОЕМ): `CAM`, `INSERTS`, `FLASHES`, `BIG`, `MUSIC`, `SILENCE`, `SFX`.
  `SPEAKER`, `VOICE`, `WORDS`, `FPS` и длительность — в блоке «файлы проекта»: их подставляют `prep`, `cut` и `transcribe`, руками не править.
  Звук в `SFX` — имя звука движка (`'whoosh'`) или путь из каталога (`'sfx/pack/pop/pop-09.wav'`).
- Блоки движения брать из `src/kit`: `presentations` (portal, blurThrough, bloom, whip, shrinkTo, lift), `backdrops`,
  `hud` (реактор, уголки прицела, захват цели, туннель, код-дождь), `poster`, `liquid`, `Porthole`, `Phone`, `BrowserCard`,
  `remocn` (эффекты текста). Готовые приёмы с кодом: `patterns/reels/*/code`.
- Видео в кадре: `<Video>` из `@remotion/media` внутри `<Sequence from={кадр}>`; обрезка начала `trimBefore` в кадрах
  композиции; у видео и картинок шире своего окна обязательно `maxWidth: 'none'`.
- Запись экрана под речь: если шаги на экране идут не в темпе голоса, перемонтировать её по опорным словам
  (кусочная скорость ffmpeg `trim` + `setpts` на каждый отрезок + `concat`, образец в `patterns/reels/r28-trend-apple`).
- Реакция на голос (реактор, эквалайзер): заранее посчитать огибающую голоса по кадрам в TS-файл (`patterns/reels/r29-jarvis-ironman/code/voice-env.ts`).
- Нет демо у продукта, но есть веб-интерфейс: запустить его фронтенд локально (зависимости `npm ci --ignore-scripts`,
  без доступа к аккаунтам) и снять покадрово `scripts/capture-ui.cjs`. Состояния двигать по таймингам речи.

## 5. Субтитры (`src/montage/Captions.tsx`)

Правила — `ПРАВИЛА/2 Субтитры.md`: защитные всегда, вид — из стиля или примера, иначе базовый.
- Базовый вид в кадре 1440×2560: Manrope 700, 80 px (60 px сетки 1080), капсула (`plate="capsule"`), подчёркнуто
  произносимое слово. «Убери капсулу» → `plate="none"`: шрифт, размер и цвет те же, мягкая тень, подчёркивания нет.
  «Убери подчёркивание» при капсуле → `mark="none"`. Субтитры не мельче 64 px в кадре 1440 (48 px при ширине 1080);
  служебные подписи стиля могут быть мельче. Поля по бокам 120–135 px.
- Строка до 5 слов, рвётся по фразе и паузе. Капсула (базовый вид по умолчанию) не уже текста, поля от 0,4 кегля.
- Место: над швом половины (centerY 1157), ниже середины на весь кадр (1467), над карточкой спикера (470),
  на живом кадре — ниже подбородка по замеру лица. Не на лице, не под окном спикера, не в зоне ника внизу, не под кнопками справа.
- Технические подписи — JetBrains Mono.

## 6. Звук

- Звук по `ПРАВИЛА/5 Звук.md` во всех стилях; правила звука стиля и звуки из кода образцов не действуют.
- Слой один на все ролики: `<Sounds cues={SFX} />` из `src/sound.tsx`, `SFX: Cue[]` — строки `[секунда, звук]`.
  Звук — раздел каталога `public/sfx/pack/КАТАЛОГ.md` по **действию**: стык `'whoosh'`, появление карточки `'pop'`,
  клик `'click'`, интерфейс `'ui'`, успех `'positive'`, раскрытие `'riser'` (кончается в эту секунду), счёт `'counter'`,
  печать `'typing'` (длительность 4-м числом: `[15.05, 'typing', undefined, 0.6]`). Слой сам берёт разные файлы раздела по
  очереди (сначала ★), соседние не повторяются. Точный файл — путь из каталога, фирменный звук стиля — путь `sfx/sheet/…`, `sfx/apple/…`.
- Громкость не указывать: стартовая из каталога подобрана по замеру каждого файла (слышно рядом с голосом, тише его).
  Нужна другая — третье число в строке. Без приглушения под речь, без множителей.
- Стили движка (`project.ts`) ставят звук сами по блокам; `cues` в `PROJECT` — добавить свои, `sfx: false` — без автоматических.
- Голос главный. Музыка на 13 дБ тише голоса (готовит `npm run music`, `ПРАВИЛА/5 Звук.md`).
- Итог выравнивается скриптом до −14 LUFS, пик до −1 dBTP (делает `npm run draft/render`).

## 7. Проверки до показа (обязательные ворота)

1. `npm run check`: типы без ошибок.
2. `npm run qa -- <id>`: `FIT PASS`. Любое `[fit]` чинить (контейнер растёт под текст, иконки не сжимаются).
3. `npm run frames -- <id>`: лист `reviews/<id>-vNNN/sheet.jpg`. Сам просмотри каждый кадр до владельца:
   пустой первый кадр, текст на лице, обрезанная голова, пустой фон после стыка, логотип не виден, субтитры мельче 64 px
   (48 px при ширине 1080; служебные подписи стиля могут быть мельче).
4. Стыки: для каждого перехода `npm run stills -- <id> <кадры…>` по 6–8 кадров внутри перехода (кадр = секунда × FPS ролика).
5. «Остановки: да» — показать владельцу **все** кадры листа, статус `AWAITING_FRAME_APPROVAL`, ждать «ок»; правки по
   номерам К → новая версия листа. «Остановки: нет» (по умолчанию) — не ждать: кадры проверить самому, лист кадров
   отдать вместе с роликом (`кадры.jpg`).

## 8. Черновик и финал

1. Согласование скриншотами (SKILL, раздел 4, начало): «ок» берётся на листе кадров, видео до него не рендерится.
   `npm run draft -- <id>` (720p, −14 LUFS) — только если ученик хочет увидеть движение или доску со сценами.
2. `npm run render -- <id> --out "../Готовое/<папка>/final.mp4"`: финал 1080×1920, 20 Мбит/с, частота кадров как в
   исходнике (`public/work/<slug>/meta.json`; нет исходника видео, только озвучка — 30 к/с). 2K или 4K — только если
   попросил ученик или так стоит в «Качество финала»: `npm run render:2k` (1440×2560, 48 Мбит/с) или `npm run render:4k`
   (2160×3840, 80 Мбит/с; исходник спикера тогда 4K).
   Своя точка входа: `--entry src/entries/<id>.tsx`.
3. Проверить файл: `ffprobe` (размер, fps, длительность, битрейт), громкость (выводит скрипт), чёрных кадров нет,
   лист кадров из готового MP4 совпадает с проверенным.
4. Положить в папку результата `Готовое/<папка>/` (или куда скажет владелец), сверить размер и контрольную сумму копии
   (`sha256sum`). Облачная папка: дождаться, что файл загрузился.
5. `work/<slug>/FINAL-REPORT.md`: файл, размер, fps, битрейт, громкость, проверки, что поменяли по правкам.
