# Нарезка

Человек записывает с запинками и повторяет фразу, пока не скажет удачно. Верный дубль — всегда
**последний полный и чистый**. В готовом ролике каждое предложение звучит ровно один раз.

- Вырезать: фальстарты, оборванные фразы, повторы, одиночные «а», «и», «что?», шум.
- Границы дублей — по тишине в звуке, а не по времени слов из расшифровки: расшифровка часто ставит слова в тишину.
- Ловить и мелкие паузы 0,2–0,5 с внутри фразы: на них сидят перезапуски одной и той же фразы. Сомнительный кусок
  расшифровать отдельно и посмотреть, полный он или оборванный.
- Точки реза: за 0,05–0,08 с до первого слова (не срезать начало) и через 0,08 с после последнего.
- Проверять все куски на скрытые фальстарты внутри, даже если ученик их не отметил.
- Фраза записана двумя кусками с вдохом посередине — оставить оба куска последнего полного дубля.
- Паузы-запинки внутри фразы убрать: мелкие (0,16–0,3 с) нарезка убирает сама. Пауза длиннее 0,3 с остаётся только
  смысловая (см. ниже). На стыках не должно щёлкать и обрезаться начало слова.
- Смысловую паузу оставить (около 0,4 с, но не больше, чем была в записи): после вопроса, перед выводом или панчлайном.
  Пример: «Знаешь, сколько это стоит? *(пауза)* Ноль рублей». В команде нарезки — плюс после куска: `3+`.
- Есть сценарий — имена и бренды из него записать в `work/<ролик>/hint.txt` строками «как слышится → как писать»
  (например «клод → Claude»): расшифровка поправит написание. После нарезки сверить речь со сценарием и перечислить
  ученику расхождения (`npm run cut:check -- <ролик> --script <файл>`).
- Есть сценарий от ученика — порядок фраз по нему, расхождения перечислить в ответе.
- Проверка: готовую нарезку расшифровать заново — каждое предложение один раз, целиком, по порядку.
- Голую нарезку (`cut_preview.mp4`) сразу показать ученику и не ждать ответа: работать дальше.
  Скажет «плохо» — переделать нарезку и всё, что после неё.
- «Нарезать дубли — нет» в настройках: видео уже нарезано, ничего не вырезать.
- «Просто нарежь» / «только нарезка»: без субтитров, музыки и графики — готовый файл нарезки 1080×1920, частота как в
  исходнике, громкость выровнена (`npm run cut:final`).
- «Открой нарезку в Remotion»: нарезка со звуком в браузере (Remotion Studio), у каждого куска номер и время.
  Говоришь агенту, что поправить («кусок 3 начни раньше», «выкинь кусок 5»), — сразу видишь результат (`npm run cut:edit`).
- «Открой в Premiere, подправлю»: XML-проект для Premiere Pro, на таймлайне те же куски из полной записи, стыки можно
  растягивать (`npm run cut:premiere`). Импорт: Premiere → Файл → Импорт → XML.
