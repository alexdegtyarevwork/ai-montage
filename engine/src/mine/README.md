# Ролики ученика

Здесь живёт код твоих роликов: каждая папка `<slug>/` — один ролик. Её создаёт `npm run new -- <slug> <стиль>`:
- `Reel.tsx` + `words.ts` — свой ролик по шаблону (стиль `custom` или `geroy`);
- `project.ts` — ролик на движке стилей (стили 1, 2 и 5–13).

Студия находит ролики сама, регистрировать их не нужно. Папка не уходит в git: обновление набора её не трогает.
Блок между строками `// >>> файлы проекта` и `// <<<` дописывают команды `prep`, `cut` и `transcribe` — руками его не правь.
