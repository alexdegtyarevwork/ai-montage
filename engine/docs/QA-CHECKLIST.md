# Проверка перед выдачей

Полный список для агента: раздел 4, шаг 10 навыка `.claude/skills/ai-montage/SKILL.md` и раздел 7 справочника
`reference/04-build.md`. Коротко:

- `npm run check`, `npm run qa -- <id>` (FIT PASS), `npm run qa -- FitTest` (обязан FIT FAIL).
- Лист кадров К001… просмотрен целиком, стыки проверены по 6–8 кадров. Показать владельцу и ждать «ок» — только при
  «Остановки: да» (`ПРАВИЛА/1 Настройки.txt`); при «нет» (по умолчанию) агент проверяет сам и отдаёт лист вместе с роликом.
- Кадр 0 не пустой; огромная фраза-хук — только если её задал стиль или попросил ученик; текст не на лице, голова не обрезана.
- Черновик 720p — только при «Остановки: да», тогда ждать «ок». Финал: размер (1080p; 2K или 4K по просьбе ученика),
  fps как в исходнике, битрейт замерены по файлу, −14 LUFS, пик ≤ −1 dBTP, чёрных кадров нет.
