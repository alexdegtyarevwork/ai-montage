# Готовые сообщения агенту

Главный список промптов для ученика — `ПРОМПТЫ.txt` в корне набора: монтаж, правки по кадрам, «запомни правило»,
«запиши стиль», обновление набора. Начинать с него. Ниже только несколько дополнительных примеров.

Хочешь, чтобы агент останавливался и ждал «ок» на плане и черновике, — поставь «Остановки: да» в `ПРАВИЛА/1 Настройки.txt`.
По умолчанию («нет») он монтирует сразу до готового ролика и называет свои решения в ответе.

## Сделать Reels из длинного видео

```text
Источник: [ссылка или файл]. Найди 3 сильных фрагмента для Reels по 30–45 секунд.
Для каждого дай главную мысль и призыв в конце. Ничего не монтируй, пока я не выберу фрагмент.
```

## Повторить стиль ролика-примера

```text
Повтори стиль ролика из папки «Референсы». Мне нравится: [темп, шрифт, переходы, звук].
Запиши этот стиль как мой: [название].
```

## Финальный рендер после проверки (если стоит «Остановки: да»)

```text
Кадры и черновик подходят. Запускай финальный рендер, проверь видео и звук, затем дай путь к MP4 и коротко, что проверено.
```
