# Откуда взят код

Версия 2.0 (26.09.2026) собрана из рабочего конвейера монтажа: движок стилей, блоки движения, субтитры, скрипты проверки
и рендера, звуки, логотипы, 3D-предметы и код роликов 19–29 с картами монтажа (`patterns/reels`). Исходные записи, голос
и ключи не переносились. Личные пути в документах заменены заглушками. Шрифты SF Pro Display, SF Pro Text и SF Mono входят
с версии 2.1 (`public/fonts`).
