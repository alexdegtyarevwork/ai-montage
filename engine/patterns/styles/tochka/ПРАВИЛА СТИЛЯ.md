## Ролик
Начало ролика:
Режим текста: только анимированные тексты: ролик-плакат под музыку. Если в ролике есть речь, ТОЧКА идёт только главами-перебивками по 2 с, а речь закрывают субтитры по правилам базы
Раскладка кадра: без спикера; со спикером ТОЧКА только перебивки глав между частями
Цвета (до 3): чернила #0F100D, бумага #EFEBDF, красный сигнал #DE4E2C
Плашки и графика: сверхузкий гротеск КАПСОМ Bebas Neue Bold 225–270 px; HUD и подписи SF Pro Display 600 КАПСОМ с разрядкой 0,14 em; знак-подпись Manrope 800 строчными. Проводник: одна красная точка, она падает, ударяется, отскакивает в точку после слова, раздувается в фон, сжимается ирисом, кружит кометой вокруг знаков. HUD с таймкодом и главами
Переходы и темп: глава = такт (2 с при 120 BPM), смена за 1,5 кадра до доли. Стыки только из предмета: точка раздувается в фон, ирис в точку и другие. Фоны глав чередуются: чёрный → красный → бумага → чёрный → бумага. Печать 60 знаков в секунду
Звуки: по `ПРАВИЛА/5 Звук.md`, общие правила набора главнее этой строки (в образце: ведёт музыка; подъём на последней доле каждого такта, удар на падение точки и на подпись, тики на смену фигур)

## Особые правила стиля
- Статус: стиль 18 в основном списке стилей 1–21, образец собран 08.10.2026.
- Предвосхищение везде: знак сжимается перед каждым морфингом, точка перед прыжком, диск перед заливкой кадра.
- Каждое событие на долю музыки.
- Нельзя: градиенты, тени, стекло, больше трёх цветов, событие мимо доли, глава длиннее такта без причины.
- Для вступления серии, анонса, итога, ролика без слов под музыку 10–20 с.
