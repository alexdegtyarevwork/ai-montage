# Номера стилей

Нумерация набора сквозная, без пропусков: 1–21. В старых пометках кода образцов СИМБИОЗ может называться «16», а ЭСТАФЕТА —
«без номера»: в наборе это 19 и 20. У каждого стиля в его папке лежит `ПРАВИЛА СТИЛЯ.md` (вид субтитров и ролика по шаблону
`Стили/_ШАБЛОН`) и, если есть, `PATTERN.md` (механика и код образца).

Превью-композиция: id в студии Remotion, кадр которой лучше брать для картинки стиля на доске
(`scripts/demo-boards.mjs`, список `STYLES`; `npm run boards` пересобирает доски и листы кадров на записи владельца). Композиции 16–18 живут в отдельной точке входа `src/entries/md-styles.tsx`,
остальные в `src/index.ts`.
