## Ролик
Начало ролика:
Режим текста: только анимированные тексты: слова речи садятся на строку, фраза строится быстрее голоса и ждёт его (в образце субтитров нет)
Раскладка кадра: голос без лица на весь кадр или половина экрана: спикер снизу, плёнка сверху
Цвета (до 3): тёплая тьма #0E0D09, кремовый текст #F1E6D2, сигнальный оранжевый #FF7A3D; свечение снизу #C2461F
Плашки и графика: SF Pro Display Light курсивом: крупные планы 150–180 px, фраза 63–69 px. Проводник: оранжевая искра, она ведёт слова → полутоновый диск на наезде → логотип-звёздочка → комета пишет название → чип → курсор → лупа → каретка. Призрак следующего слова, «дышащая» строка, акцент цветом и рукописным подчёркиванием, связка «знак + имя» всегда по центру
Переходы и темп: наезд ×2,6–3 склейкой с расфокусом и растром; уход «текст вверх, точка вниз» → 2 пустых кадра → искра снизу → чёрный кадр → логотип из пикселей на дропе; световая полоса стирает слово; чип в поле ввода, поле растёт в окно-кинескоп с результатом; склейки внутри постоянной рамки; барабан страниц; смаз-уход. Движение на двойках
Звуки: по `ПРАВИЛА/5 Звук.md`, общие правила набора главнее этой строки (в образце: почти без звуков интерфейса; ведёт музыка: тихое вступление → подъём → дроп на логотипе → грув → музыка уходит до подписи)

## Особые правила стиля
- Статус: стиль 16 в основном списке стилей 1–21, образец собран 08.10.2026.
- Фактура обязательна: движение на двойках, зерно, ореол, виньетка, живое свечение снизу; хроматизм только на крупных планах.
- Проводник никогда не стоит: дрейфует, патрулирует край кадра, после темноты всплывает с приближением.
- Нельзя: белые фоны, плоская запись экрана без рамки, плавное движение без двоек, больше одного сигнального цвета.
- Для показа результата нейросети или продукта «как кино»: запуск, трейлер, кейс.
