# 12 — ПОДКАСТ

**Статус:** формат сдан в серии нарезок подкаста
**Композиции:** `PODCAST-Reels`, `PODCAST-YouTube`
**Код:** `src/styles/podcast.tsx` + `src/styles/skinned.tsx` с `marker: true`; нарезка подкаста — общая (`npm run takes`, `npm run cut`)
**Ролик-образец:** `patterns/reels/podcast-split/frames.jpg`

## Механика
- Кадр подкаста снизу (в YouTube — слева), сверху доска: белый лист с жёсткой рамкой и тенью, заголовок с маркером.
- Пункты отмечаются маркером-выделителем, числа оранжевые, схема — узлы в рамках; шов между доской и кадром — тонкая линия.

## Когда брать
Нарезки из подкаста и интервью, где говорят двое и лицо важно.

## Раскладка
`speaker: podcast`; зона графики — доска.

## Что менять под каждый ролик
Какие термины и цифры выносятся на доску, цвет подложки по блоку.

## Что владелец принимал и отклонял
- Принято: доска с терминами и цифрами над кадром; фрагмент — законченная мысль, понятная без начала разговора.


## Как собрать ролик в этом стиле

Проект создаёт команда `npm run new -- <slug> PODCAST`: файл данных `src/mine/<slug>/project.ts` (те же блоки `hook`, `list`,
`stat`, `logos`, `flow`, `cta`)
со строкой `STYLE = 'PODCAST'`. Композиция появляется в студии в папке Projects. Сменить стиль = поменять `STYLE`.

Своя механика блока, которой нет в стиле, пишется рядом в `src/mine/<slug>/` из блоков `src/kit`.
