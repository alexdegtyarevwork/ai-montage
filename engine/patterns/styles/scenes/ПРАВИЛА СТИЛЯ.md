# Стиль: 4 СЦЕНЫ

Меняет только вид. Защитные правила из «ПРАВИЛА/2 Субтитры.md» действуют всегда.
Пустое поле — как в базовом виде. Размеры — для кадра 1080 по ширине.

## Субтитры
Шрифт и насыщенность: Manrope 400
Размер: как в базе (в коде образца 40 px, это меньше защитного минимума 48 px)
Цвет текста: светлый #F2F3F5 на тёмном фоне, тёмный #101214 на белом
Подложка: нет, читаемость держит тень
Выделение слов: подчёркивание произносимого слова
Цвет выделения: из «1 Настройки.txt», по умолчанию #FBB931 (в образце — мятный #3DEDC3)
Слов в строке / строк: страница по фразе, до 2 строк
Регистр:
Место: одна строка около 57% высоты, две строки около 61%; графика выше, до 57%
Появление и уход: страница проявляется из лёгкого размытия за 0,2 с
Звук появления:

## Ролик
Начало ролика: свой герой хука с кадра 0 (в образце 3D-иллюминатор с «$7», его не копировать)
Режим текста: субтитры
Раскладка кадра: спикер в карточке по формату внизу
Цвета (до 3): фон по смыслу блока (в образце чёрный → закатное небо → графит → мятное свечение → белый)
Плашки и графика: 3D-иллюминатор, 3D-телефон с перепиской, тогл «вручную → автомат», по которому кликает курсор; настоящие записи экрана почти на всю ширину, приватное размыто
Переходы и темп: фон меняется каждые 3–7 с по смыслу. Стыки: влёт в окно предмета, размытие сквозь цвет, свечение, рывок с размытием по оси, сжатие в узел схемы, уход в тёмное. Переход съедает свою длину из стыка, смена фона попадает ровно на фразу
Звуки: по `ПРАВИЛА/5 Звук.md`, общие правила набора главнее этой строки (в образце: под каждое видимое действие (в образце 31 событие за 56 с), на стыках вуши)

## Особые правила стиля
- У каждого стыка своя причина в речи.
- Предмет появляется, когда камера уже доехала, и не на полосе субтитров.
- На отъезде камеры текст в кадре не мельче минимума: размер шрифта в мире = минимум, делённый на масштаб камеры.
- Иллюминатор, наклейки «$7 / $25», тогл и порядок сцен образца в новый ролик не переносить.
