# 8 — PULSE (звук ведёт монтаж)

**Статус:** кандидат: механика одобрена как направление, визуал владелец не утверждал
**Композиции:** `PULSE-Reels`, `PULSE-YouTube`
**Код:** `src/styles/pulse.tsx`, пульс — `speech()` в `src/styles/speaker.tsx`
**Ролик-образец:** `patterns/reels/pulse-narrator/frames.jpg` (демо с кукольной головой)

## Механика
- Круг-рассказчик с оранжевым кольцом пульсирует в такт речи (энергия считается по словам расшифровки).
- На каждом блоке выпрыгивает крупный 3D-предмет (`public/objects`), предметы и световые пятна фона дышат с голосом.
- Мало текста, крупные предметы, тёплый светлый фон.

## Когда брать
Ролик почти без съёмки лица, аудио-первый формат, короткий тезис.

## Раскладка
Спикер — круг справа снизу (`speaker: circle`). Свою анимированную голову можно подставить вместо записи.

## Что менять под каждый ролик
Какой предмет на каком слове, где круг-рассказчик.

## Что владелец принимал и отклонял
- Урок из демо: плашка «А база?» обрезала текст — контейнер растёт под содержимое (минимум 340 px там), проверка `qa-fit`.


## Как собрать ролик в этом стиле

Проект создаёт команда `npm run new -- <slug> PULSE`: файл данных `src/mine/<slug>/project.ts` (те же блоки `hook`, `list`,
`stat`, `logos`, `flow`, `cta`)
со строкой `STYLE = 'PULSE'`. Композиция появляется в студии в папке Projects. Сменить стиль = поменять `STYLE`.

Своя механика блока, которой нет в стиле, пишется рядом в `src/mine/<slug>/` из блоков `src/kit`.
