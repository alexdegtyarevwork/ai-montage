# AI монтаж — инструкция для агента (Claude, Codex и любых других)

Эта папка — рабочее место ученика курса «AI монтаж». Работай **только** по навыку
`.claude/skills/ai-montage/SKILL.md`: прочитай его целиком в начале каждого чата и следуй ему.
Настройки и правила ученика — в папке `ПРАВИЛА` (читай перед каждым роликом). `ПРАВИЛА/7 Мои правила.md` главнее всех
остальных правил; главнее только просьба ученика в этом чате.

- Монтаж только на Remotion (папка `engine`). HyperFrames и другие видеонавыки не использовать.
- Работать только внутри этой папки. Пароли в чат не просить.
- Отвечать по-русски, коротко, без терминов: ученик — новичок.

## Если ты Codex
- Навыки для тебя продублированы указателями в `.agents/skills/` — полный текст в `.claude/skills/`.
- Установке и монтажу нужны интернет (сток, модель речи, программы) и запись вне песочницы (установка программ, рендер
  через браузер). Если команда упирается в песочницу или просит разрешение — попроси ученика один раз включить режим
  «Full access» (переключатель разрешений под полем ввода), затем повтори команду. Команды те же, что для Claude;
  на Windows — `npm.cmd`/`npx.cmd` в PowerShell.
- Команды ученика «/info» и «/storybook» в Codex приходят обычным текстом: выполняй их по файлам `.claude/commands/info.md`
  и `.claude/commands/storybook.md`.
