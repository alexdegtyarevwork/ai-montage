# AI монтаж

Набор курса «AI монтаж». Ты кладёшь своё видео в папку и пишешь Claude одну фразу. Claude сам монтирует
вертикальный Reels на движке Remotion: режет дубли, ставит субтитры по словам, добавляет вставки со стока (Pixabay; Pexels — если попросишь), графику, звуки и музыку из готового пака,
проверяет кадры и отдаёт готовый ролик.

> **Для ИИ-агента (Claude, Codex), которого попросили «установи этот набор».** Определи систему сам и запусти в фоне
> одну команду, дождись конца (15–40 минут), по ходу коротко рассказывай. Уже установленное установщик проверяет и не ставит
> заново (программы, Remotion, браузер, модель речи, пробный ролик): повторный запуск только обновляет набор и доставляет недостающее. Установщик сам ставит всё нужное
> (Git, Node.js, FFmpeg, Python, Visual C++ / инструменты Apple, движок и модель речи) и пишет журнал `install.log` в папку набора.
> - Windows (PowerShell): `[Net.ServicePointManager]::SecurityProtocol='Tls12'; irm https://raw.githubusercontent.com/alexdegtyarevwork/ai-montage/main/install/install-windows.ps1 -OutFile $env:TEMP\ai-montage-install.ps1; powershell -NoProfile -ExecutionPolicy Bypass -File $env:TEMP\ai-montage-install.ps1`
> - Mac (Apple и Intel): `curl -fsSL https://raw.githubusercontent.com/alexdegtyarevwork/ai-montage/main/install/install-mac.sh | bash`
>
> Строка «ОШИБКА» — сделай то, что написано после «Что сделать», и запусти команду снова (она продолжит с места остановки).
> Окна Windows «Разрешить изменения?» и Mac «Установить инструменты разработчика», пароль от Mac — объясни человеку простыми
> словами, что нажать; пароль он вводит сам в окне системы, не в чат. Шаг упал из-за связи — просто запусти команду снова.
> В конце скажи коротко и только это: «Готово ✅ Набор установлен. Полностью закройте Claude (или Codex), откройте снова —
> и приступайте к следующему уроку.» Подробный отчёт о шагах, пробный ролик и выбор папки не расписывай.

## Что нужно

| | |
|---|---|
| Windows | Windows 10 (версия 1809 и новее) или 11, 64-бит. Подходит и обычный процессор, и ARM. |
| Mac | Процессор Apple (M1 и новее) или Intel. На Mac должна стоять **macOS 15 Sequoia или новее**: старше Remotion не запускается. На Intel всё работает, но медленнее. |
| Место | 15 ГБ свободно на диске |
| Интернет | Нужен на время установки, при необходимости с VPN |
| Агент | Приложение Claude с подпиской Pro или Max, или ChatGPT с Codex |

## Установка (один раз, 15–40 минут)

### Самый простой способ: промпт в Claude

1. Открой Claude, вкладку **Code**, нажми **Select folder** и выбери папку «Документы».
2. Отправь сообщение:

```
Установи набор AI монтаж (ai-montage). Запусти в фоне команду для моей системы и дождись конца (15–40 минут),
по ходу коротко рассказывай, что происходит. Если появится строка «ОШИБКА» — сделай то, что написано после
«Что сделать», и запусти команду снова.
Windows (в PowerShell): [Net.ServicePointManager]::SecurityProtocol='Tls12'; irm https://raw.githubusercontent.com/alexdegtyarevwork/ai-montage/main/install/install-windows.ps1 -OutFile $env:TEMP\ai-montage-install.ps1; powershell -NoProfile -ExecutionPolicy Bypass -File $env:TEMP\ai-montage-install.ps1
Mac: curl -fsSL https://raw.githubusercontent.com/alexdegtyarevwork/ai-montage/main/install/install-mac.sh | bash
```

3. Когда Claude спрашивает разрешение, нажимай «Allow». Windows до трёх раз спросит «Разрешить изменения?» — «Да». Mac покажет «Установить инструменты разработчика» — «Установить», «Принимаю»; на Mac с M1+ попросит пароль от Mac в своём окне.

### Вручную, через терминал

#### Windows

1. Нажми «Пуск», напиши `PowerShell` и открой **Windows PowerShell**.
2. Вставь строку ниже (правой кнопкой мыши) и нажми Enter:

```powershell
[Net.ServicePointManager]::SecurityProtocol='Tls12'; irm https://raw.githubusercontent.com/alexdegtyarevwork/ai-montage/main/install/install-windows.ps1 -OutFile $env:TEMP\ai-montage-install.ps1; powershell -NoProfile -ExecutionPolicy Bypass -File $env:TEMP\ai-montage-install.ps1
```

3. Windows до трёх раз спросит «Разрешить этому приложению вносить изменения?». Каждый раз нажимай «Да».
4. Подожди, пока не появится строка `Готово ✅`. Набор будет лежать в папке `C:\ai-montage`.

#### Mac (и Apple M1+, и Intel)

1. Нажми ⌘ + Пробел, напиши `Терминал` и нажми Enter.
2. Вставь строку ниже (⌘ + V) и нажми Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/alexdegtyarevwork/ai-montage/main/install/install-mac.sh | bash
```

3. Появится окно «Установить инструменты разработчика». Нажми «Установить», потом «Принимаю».
4. Подожди, пока не появится строка `Готово ✅`. Набор будет в папке пользователя: в Finder открой «Переход» → «Домой» → `ai-montage`.

## Монтаж

1. После установки полностью закрой Claude и открой его снова.
2. Во вкладке **Code** нажми **Select folder** и выбери папку `ai-montage`.
3. Положи видео в папку `ai-montage/Видео`, начни новый чат и отправь:

```
Смонтируй Reels из самого нового видео в папке «Видео»
```

Готовый ролик появится в папке `ai-montage/Готовое`. В первый раз Claude попросит бесплатный ключ Pixabay для
видеовставок: он сам подскажет, где его взять, и сам впишет. Свои картинки, видео и звуки можно просто прислать в чат. Остальные промпты, для правок и для своих правил, лежат в `ПРОМПТЫ.txt`.

С Codex всё так же: открой папку `ai-montage` в Codex и отправляй те же сообщения. Перед установкой и монтажом включи
в Codex режим **Full access** (переключатель разрешений под полем ввода): набору нужен интернет и запись вне папки проекта.

## Обновление

Напиши Claude в папке набора «Обнови набор» или ещё раз выполни команду установки. Твои видео, готовые ролики, ключи
и правки в `ПРАВИЛА` при обновлении сохраняются.

## Что внутри

| Папка | Что там |
|---|---|
| `Видео` | твои исходники |
| `Музыка`, `Звуки`, `Файлы`, `Референсы` | своя музыка; свои звуки-эффекты; логотипы и скриншоты; ролики, стиль которых нужно повторить |
| `Стили` | твои собственные стили: одна папка — один стиль. Стили набора 1–21 лежат в `engine/patterns/styles`, копировать их сюда не нужно |
| `Готовое` | результат: `final.mp4`, нарезка без графики, лист кадров для правок |
| `ПРАВИЛА` | настройки: субтитры, нарезка, звук, стили, твои правила. Их можно менять. |
| `ПРОМПТЫ.txt` | готовые сообщения для Claude |
| `engine` | движок Remotion: стили, субтитры, пак шрифтов, звуков (`public/sfx/pack`), музыки (`public/music`) и графики |
| `install` | установщики для Windows и Mac |
| `.claude/skills` | навык для Claude: открываешь папку, и он подхватывается сам |

Remotion в репозитории нет, и отдельным плагином его ставить не нужно. Установщик скачивает его командой (`npm ci`)
в `engine/node_modules`, вместе с браузером для рендера и распознаванием речи whisper.cpp с моделью (~1,5 ГБ).
HyperFrames набору не нужен.
